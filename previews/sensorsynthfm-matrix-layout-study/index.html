Comparison note: the current side is a layout reconstruction from the verified source and 1210 × 834 geometry receipt. XCTest exported the available screenshot with unusable orientation metadata, so it is preserved as evidence rather than presented as a clean landscape capture.

What this revision changes

  • Matrix densityAll nine current sensor sources appear in aligned columns. Target rows stay readable and each route cell remains at least 56 points.
  • Route editingThe selected route stays directly below the matrix. The bipolar control uses the full flexible width and keeps a visible center.
  • Reset without ZEROThe signed amount becomes the 48-point reset target. The separate full-width ZERO bar disappears.
  • Secondary railScene, base/live context, handedness, and diagnostics stop competing with the routing surface.

Decision points

  1. Does the nine-source matrix feel dense but usable, or merely small?
  2. Is tapping the signed amount to reset understandable enough?
  3. Does the right rail contain the right secondary material?
Evidence and boundaries
  • Current candidate: c5d3472, clean local branch.
  • Recorded validation: 20 of 20 Xcode tests, generic iOS build, simulator geometry, physical signing, install, launch, and error-free startup.
  • Preserved feedback: space use poor, ZERO wastes space, plus/minus order must reverse, grid should become more Ableton-like over time.
  • Not tested here: physical dexterity, haptics, bottom gesture avoidance, audio behavior, or Swift feasibility.
  • Parked: direct adjustment inside matrix cells.
