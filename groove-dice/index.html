HOW THIS CAME ABOUT

Groove Dice started with a simple question: could the rhythmic logic in Attack Magazine’s Beat Dissected series become an instrument instead of another folder of reference material? I wanted a quick way to roll a pattern, hear why it worked, and then pull it apart through density, feel, timing, velocity, and individual notes.

I worked through the instrument with Clarence, using OX Alpha for implementation passes while I stayed on the musical and interaction decisions. The first versions repeated themselves, ignored controls, cached the wrong build, and occasionally refused to let me edit while the beat was playing. That friction was useful. Every failure forced the rhythm engine and the interface to explain themselves more clearly.

It is still an experiment, but it is one I can actually use. That was the bar.

This is an experimental build with OX Alpha. Learn more about OX Alpha.
