Two MIDI tools that survived Live

Rhythm Dice and Cymbal Phrase turn bounded musical rules into MIDI without hiding the result behind random noise. Both run inside Ableton Live 12 as narrow Max for Live Generator Tools. Download the devices, put them in your User Library, and use them on any MIDI clip.

I directed the product design, musical goals, Live testing, and listening decisions. Clarence assisted with research synthesis, code, tests, packaging, documentation, and this report under my direction and review.

Small report

Random notes were never the goal.

The useful part of a groove is the relationship between events. Anchors hold the identity of a pattern together. Density, timing, velocity, and seeded variation change what happens around them. Rhythm Dice applies that idea across eight rhythm families, including true five-beat bars.

Cymbal Phrase applies the same discipline to hats, crashes, and rides over phrases from 1 to 64 bars. It grew from a 46-record research corpus: 24 human performances, six open-source fixtures, and 16 original analytical MIDI examples. The mixed-license corpus is not bundled here. The device source and compiled tool are.

The musical logic had to survive a very small interface, Live's synchronous MIDI Tool transaction, and a real Drum Rack map. That friction made the tools better.

Installation

Put the tool where Live can find it.

Requires Ableton Live 12 and Max for Live.

  1. 01

    Download the `.amxd` file for the tool you want.

  2. 02

    Open Ableton Live 12, then drag the file into User Library in Live's Browser.

  3. 03

    Or copy it into Music/Ableton/User Library/MIDI Tools/Max Generators inside your home folder.

  4. 04

    Give Live a moment to index the file. If it does not appear right away, let the User Library scan finish before copying it again.

  5. 05

    Select a MIDI clip, open the clip's Generate panel, and choose the tool from the User section.

  6. 06

    Set the controls, roll or click New, then click Live's Apply icon to write the notes into the clip.

Rhythm Dice's Five Count family writes real five-beat bars. Set the clip to 5/4 and use a loop length of five beats per generated bar.

What still matters

The limits are part of the release.

Cymbal maps vary

Drum Rack notes depend on the preset. CP-004 targets the stock 16-pad map used during Live testing. It does not claim universal rack compatibility.

CP-004 is still beta

The latest hands-on report says it appears stable and works well. Full layout, mapping, New, Push bank, and musical-result acceptance remains open.

Push means Control Mode

Live MIDI Tools do not run on Push Standalone. The eight-parameter bank is for Push controlling Live.
